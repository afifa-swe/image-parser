# Image Parser

Веб-приложение для парсинга и обработки изображений с любой страницы в интернете.

## Возможности

- Загрузка всех изображений с указанной веб-страницы по URL
- Фильтрация по минимальной ширине и высоте — картинки меньше заданных размеров не загружаются
- Обработка найденных изображений: уменьшение по высоте до 200px, обрезка по ширине до 200px (квадрат)
- Наложение произвольного текста на каждое изображение
- Отправка формы через AJAX без перезагрузки страницы
- Сохранение обработанных изображений на сервере с отображением при перезагрузке страницы

## Стек технологий

- **PHP 8.4**, **Symfony 8.0**
- **Intervention Image 3** (GD-драйвер) — обработка изображений
- **Symfony DomCrawler** — парсинг HTML-страниц
- **Symfony HttpClient / Guzzle** — загрузка страниц и изображений
- **Twig** — шаблонизатор
- **Vanilla JS (Fetch API)** — AJAX-обработка формы

## Требования

- PHP >= 8.4
- Расширения PHP: `gd`, `ctype`, `iconv`
- Composer

## Установка и запуск

```bash
# Клонировать репозиторий
git clone <url> image-parser
cd image-parser

# Установить зависимости
composer install

# Запустить dev-сервер
php -S 127.0.0.1:8080 router.php
```

Открыть в браузере: **http://127.0.0.1:8080/**

## Использование

1. Ввести URL страницы (например `https://habr.com`)
2. Указать минимальную ширину и высоту изображений (по умолчанию 100px)
3. Ввести текст, который будет наложен на каждое изображение
4. Нажать **«Загрузить изображения»**
5. Обработанные изображения появятся в галерее без перезагрузки страницы
